# Create the GitHub repo and push

Your project is committed locally. To put it on GitHub:

## 1. Create the repo on GitHub

Open this link (it pre-fills the repo name **obsidian_site**):

**https://github.com/new?name=obsidian_site**

- Leave "Add a README" **unchecked** (you already have code).
- Click **Create repository**.

## 2. Push from your project folder

In Terminal:

```bash
cd /Users/collin/Documents/Obsidian_site
git push -u origin main
```

Done. Your repo will be at: **https://github.com/CollinMartin12/obsidian_site**
